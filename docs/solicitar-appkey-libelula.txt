-----------------------------------------------------------------------
QUE HACER CUANDO LLEGA EL APP KEY
-----------------------------------------------------------------------

Pegarlo en backend/.env y completar el bloque de pasarela:

  QR_PROVEEDOR=libelula
  QR_APPKEY=<pegar aqui el appkey>
  QR_BASE_URL=http://www.todotix.com:10888
  QR_CALLBACK_BASE=<URL publica del tunel>
  QR_URL_RETORNO=http://localhost:4200/ventas/punto-venta
  QR_RAZON_SOCIAL=<razon social>
  QR_NIT=<NIT>

Despues:

  python scripts/verificar_libelula.py

  # el script imprime exactamente que falta, o confirma que la
  # configuracion esta lista

  powershell -File scripts/probar_tunel_qr.ps1

  # levanta el backend y un tunel publico, y comprueba que la ruta
  # del webhook sea alcanzable desde internet

  python scripts/verificar_libelula.py --conectar

  # registra una deuda real de Bs. 1 y consulta la conciliacion.
  # Aca es donde se confirma si el contrato asumido en el codigo
  # coincide con lo que responde Libelula.
